# MCP・Electronのデータの扱い — 0.6.1（2026-11-23）

これは実装・設定・架空ページでの動作を点検した記録です。第三者監査や、過去のすべての通信を調べた漏えい調査ではありません。「情報が絶対に漏れない」という保証はできません。

## 情報が渡る先

| 場面 | 情報の扱い |
|---|---|
| 通常の閲覧 | 閲覧先と、そのページに組み込まれた外部サービスへ通信します。Portio独自の解析・広告・クラウド同期処理はありません。 |
| MCPでの読み取り | 作業用タブの本文、通常の入力欄の値、タイトル、URLのパス、操作対象の情報が接続したAIサービスへ渡ります。本文にある個人情報や機密情報も含まれ得ます。ローカルMCPであっても、AIによる処理までMac内で完結するわけではありません。 |
| 保存したログイン情報 | Macのキーチェーンで保護された鍵を使って暗号化し、Mac内へ保存します。MCPに保存済みパスワードやCookieを取り出すツールはありません。 |
| 公開・配布 | アプリ本体はソース・リソース・ライセンス・必要な実行環境から作成し、利用者プロファイルや検証データを含めません。ソース公開と閲覧データの保存先は別です。 |

パスワード・確認コード等の識別できる入力欄は読み取り対象から除外します。ただし、サイトが秘密を通常の本文や独自の入力欄に表示した場合まで、すべて識別できる仕組みではありません。

## 接続とページの制限

- MCPは標準入出力とMac内の私有ソケットを使い、ネットワーク向けの待ち受けポートを開きません。起動ごとの接続鍵と所有者限定のファイル権限を使います。
- 同じMacアカウントで動く悪意あるソフトや、侵害されたAIクライアントから保護する境界ではありません。連携を有効にしたクライアントは、ログイン済みの新タブを開いて操作できます。
- 作業ごとに新しいタブを作り、その接続の作業識別子に限定します。既存タブの列挙・本文取得や任意JavaScript実行のツールはありません。
- ページの移動、タブの選択変更、古い操作情報、確認ダイアログ中の操作を制限します。別サイトへ移動した後は読み取りを止めますが、ページ自身の通信をすべて遮断する機能ではありません。
- スペースは依頼内容・プロジェクト設定からAIが判断し、不明・矛盾がある場合だけ確認します。この判断はAIへの指示です。アプリ側は確定したスペースを必須とし、省略時の推測や両アカウントの試行を行いません。
- 外部ページはsandbox・contextIsolation・webSecurityを有効にし、Node.jsへのアクセスを無効にしています。

## 点検の範囲と残る課題

- 新しいElectron 45.4.1を採用し、上流のChromium等の修正を取り込みました。[公式リリース情報](https://releases.electronjs.org/release/v45.4.1)
- 開発用の間接依存も互換性のある修正版へ更新し、更新時の`npm audit`は検出0件でした。これはElectron・Chromiumや未知の欠陥を含めた無欠陥の証明ではありません。
- ソース公開前のファイル確認と、取得済みGit履歴の代表的な秘密情報パターンの検査で、利用者の保存ファイル・認証トークンの混入は検出されませんでした。任意の個人情報を完全に判別する検査ではありません。
- 操作範囲・スペース分離・機微な入力欄の除外は架空データで検証します。結果と未確認の範囲は[TESTING.md](../TESTING.md)に記録しています。
- 自動更新は未実装です。[Electronの公式セキュリティ案内](https://www.electronjs.org/docs/latest/tutorial/security)に沿って更新を続ける必要があります。Apple Developer ID署名・公証、第三者による侵入テストも未実施です。

AIへ渡った内容の保存・学習利用は、利用するAIサービスの契約と設定に従います。個人のChatGPTアカウントでCodexを使う場合、学習利用はChatGPTのデータコントロールで確認できます。学習をオフにすることと、AIサービスへ内容を送らないことは別です。[OpenAIの公式説明](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)

Portioの「AI連携」から連携を停止できます。保存パスワードの保護と限界は[パスワード機能の点検](SECURITY-REVIEW.md)も参照してください。
